## Tips
- **JPG format** is recommended for all photos
- Photos will be **automatically resized** by CSS, so any dimension works
- For best quality, use photos at least **800px wide**
- The memory gallery uses a **4:3 aspect ratio** crop
- Friend photos are displayed as **circles**, so center the face in the image
